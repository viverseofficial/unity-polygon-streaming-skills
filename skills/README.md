# Skills Index

Skills for the Viverse Polygon Streaming Unity SDK (`com.viverse.polygon-streaming`).

| Skill | Description |
|-------|-------------|
| [unity-polygon-streaming-quickstart](./unity-polygon-streaming-quickstart/) | Install the package, add `StreamController` + `StreamingModel` to a scene, configure the `PolygonStreaming` layer. |
| [unity-polygon-streaming-static-models](./unity-polygon-streaming-static-models/) | Stream static GLB / FBX models, override materials, swap URLs at runtime, fetch collider meshes. |
| [unity-polygon-streaming-animated-glb](./unity-polygon-streaming-animated-glb/) | Play embedded animation clips via `StreamingModelAnimator` + a custom `RuntimeAnimatorController`. |
| [unity-polygon-streaming-vrm](./unity-polygon-streaming-vrm/) | Stream VRM 1.0 avatars: expressions, look-at, spring bones, VRMA, Mecanim humanoid, MToon. |
